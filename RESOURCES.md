# Study Notes — Sources and Reference

## Content source

- Learner-provided raw notes are the primary content source. Missing or contradictory details will be flagged rather than silently filled in.
- Subject syllabi in `subject/<subject folder>/syllabus.txt` define the topic order and course scope.

## Visual reference

- [Making Software](https://www.makingsoftware.com/)
  User-selected visual reference for the editorial table of contents, typography-led layouts, and line-art figures. This is a design reference, not a source for study-note content.
