UNIT 02 SQL and PL/SQL 07 Hrs

SQL

Characteristics and Advantages; SQL Data Types and Literals; DDL, DML, DCL, TCL; SQL Operators.

Tables

Creating; Modifying; Deleting; Updating.

SQL DML Queries and Views

SELECT Query and clauses; Index and Sequence in SQL; Views: Creating, Dropping, Updating using Indexes; Set Operations; Predicates and Joins; Set membership; Tuple Variables; Set comparison; Ordering of Tuples; Aggregate Functions; SQL Functions; Nested Queries.

PL/SQL

Concept of Stored Procedures and Functions; Cursors; Triggers; Assertions; Roles and Privileges.

UNIT 03 Relational Database Design and Database Transaction Management 07 Hrs

Relational Model and Integrity

Relational Model: Basic concepts, Attributes and Domains, CODD's Rules; Relational Integrity: Domain, Referential Integrities, Enterprise Constraints.

Database Design

Features of Good Relational Designs; Normalization; Atomic Domains and First Normal Form; Decomposition using Functional Dependencies; Algorithms for Decomposition; 2NF, 3NF, BCNF.

Transactions and Serializability

Introduction to Database Transaction; Transaction states; ACID properties; Concept of Schedule; Serial Schedule; Serializability: Conflict and View; Cascaded Aborts; Recoverable and Non-recoverable Schedules.

Concurrency Control and Recovery

Lock-based; Time-stamp based; Deadlock handling; Shadow Paging and Log-Based Recovery; Checkpoints; Deferred Database Modifications and Immediate Database Modifications.

UNIT 04 NoSQL Databases 07 Hrs

Distributed Data and NoSQL

Introduction to Distributed Database System; Advantages; Disadvantages; CAP Theorem; Structured, Unstructured and Semi-Structured Data; NoSQL Database: Introduction, Need, Features; Key-value store; Document store; Graph; Wide column stores; BASE Properties; Data Consistency model; ACID Vs BASE; Comparative study of RDBMS and NoSQL.

MongoDB (with syntax and usage)

CRUD Operations; Indexing; Aggregation; MapReduce; Replication; Sharding.

UNIT 05 Advances in Databases 07 Hrs

Emerging Databases

Active and Deductive Databases; Main Memory Databases; Semantic Databases.

Complex and Nested Data Types

Semi-Structured Data; Features of Semi-Structured Data Models; JSON; XML.

Object Orientation

Object-Relational Database System; Table Inheritance; Object-Relational Mapping.

Spatial Data

Geographic Data; Geometric Data.
