THEORY · Q1

JavaScript kya hai? Features

QUESTION

What is JavaScript? Explain its features.

ANSWER

JavaScript (JS) web pages ko interactive banane wali lightweight, interpreted, high-level programming language hai. 1995 mein Brendan Eich ne Netscape ke liye banayi thi; aaj ye browser ke andar bhi chalti hai aur Node.js se server par bhi. Simple line mein: HTML = haddi (structure), CSS = kapde (style), JavaScript = dimaag (behaviour).

EXAM DEFINITION

JavaScript is a lightweight, interpreted, client-side scripting language used to make web pages interactive and dynamic.

Kahan use hoti hai (2–3 examples pakke karo): form validation (email khaali hai toh error dikhao), button click par content badalna, image slider, live search suggestions, aur Node.js se backend APIs. Java alag language hai — naam similar hai par dono ka koi direct rishta nahi (ye line examiner ko pasand aati hai).

Features — exam mein ye 7–8 points likho, har ek ke saath ek-line matlab:

  • Lightweight aur interpreted: compile karne ki zarurat nahi; browser line-by-line padhkar turant chalata hai. Isliye chhota code bhi fast test hota hai.
  • Client-side scripting: code user ke browser mein chalta hai, har chhoti cheez ke liye server par jaane ki zarurat nahi — jaise form check browser mein hi ho jaata hai.
  • Dynamically typed: variable banate waqt type likhna nahi padta; let x = 5 baad mein x = "Rohan" bhi ho sakta hai. Type value se decide hoti hai.
  • Event-driven: user ke kaam (click, typing, mouse move) par react karti hai — Q4–Q5 isi par based hain.
  • Case-sensitive: Name aur name do alag variables hain — spelling ka dhyaan rakho.
  • Platform independent (browser mein): jo code Chrome mein chalta hai wahi Firefox/Edge mein bhi chalta hai.
  • Object-based + first-class functions: objects, arrays se kaam hota hai; function ko variable mein rakh sakte ho, argument mein bhej sakte ho.
  • Huge ecosystem: React, Angular, Vue (frontend) aur Node.js, Express (backend) — ek language se full stack banta hai, isliye subject ka naam Full Stack Development hai.

2. Datatypes — 2 families: Primitive (single value): string ("Rohan"), number (85, 3.14), boolean (true/false), undefined (value di hi nahi), null (jaanboojhkar khaali). Non-primitive (collection): object, array, function. typeof operator se type check hota hai: typeof "Hi" → "string".

3. Operators — 4 groups ek example se:

let a = 10, b = 3;
// Arithmetic: + - * / %
console.log(a + b);   // 13
console.log(a % b);   // 1 (remainder)
// Comparison: == === != > <
console.log(a == "10");   // true (sirf value check)
console.log(a === "10");  // false (value + type dono check)
// Logical: && || !
console.log(a > 5 && b < 5);  // true
// Assignment: = += -=
a += 5;  // a ab 15

Yaad rakhne wali line: == sirf value dekhta hai, === value + type dono — exam mein === likhna safe answer hai.

4. Conditions aur loops (flow control):

// if-else: pass/fail check
let m = 72;
if (m >= 40) {
  console.log("Pass");
} else {
  console.log("Fail");
}

// for loop: 1 se 5 tak ginti
for (let i = 1; i <= 5; i++) {
  console.log(i);   // 1 2 3 4 5
}

// while loop: jab tak condition true
let n = 3;
while (n > 0) {
  console.log(n);   // 3 2 1
  n--;
}

5. Functions — kaam ko naam dena:

// Function banao + chalao
function greet(name) {
  return "Namaste, " + name + "!";
}
console.log(greet("Rohan"));  // Namaste, Rohan!

// Function ke fayde: reuse, chhota code, testing easy

6. Arrays aur objects — data ko pack karna:

// Array: list (index 0 se start)

console.log(fruits[1]);       // mango
console.log(fruits.length);   // 3

// Object: key-value jodi (jaise form ka data)
let student = { name: "Rohan", marks: 85 };
console.log(student.name);    // Rohan
console.log(student.marks);   // 85

JavaScript events kya hain?

QUESTION

What are JavaScript Events? Explain with examples.

ANSWER

Event matlab browser mein hone wali koi ghatna — user ne click kiya, key dabayi, mouse ghumaya, page load hua ya form submit hua. JavaScript in ghatnaon ko sunti hai aur turant react karti hai (koi function chala deti hai). Isi ko event-driven programming kehte hain (Q1 ka feature yaad karo).

EXAM DEFINITION

An event is an action or occurrence (click, keypress, load, submit) that JavaScript can detect and respond to using an event handler function.

Kaise kaam karta hai — 3 steps: 1) Event hota hai (user clicks button), 2) Browser uska naam pehchanta hai (click), 3) Handler function chalta hai (greet()). Formula: Event + Element + Handler = Interaction.

THEORY · Q5

Events handle karne ke methods

QUESTION

Explain different methods of handling JavaScript events.

ANSWER

Event handling matlab ye decide karna ki event hone par kaunsa function chalega aur usko kaise jodenge. Total 3 methods hain — easy se best tak. MCQ 6 ka answer (recommended = addEventListener()) isi answer ki last line hai.

Method 1 — Inline HTML attribute (sabse easy, purana): HTML tag ke andar hi handler likh do.

<button onclick="sayHi()">Click</button>
<script>
function sayHi() {
  alert("Hi!");
}
</script>
// Fayda: likhna easy. Nuksaan: HTML + JS mix, ek event par ek hi kaam.

Method 2 — DOM property (beech wala): JavaScript mein element pakadkar property set karo.

<button id="btn2">Click</button>
<script>
document.getElementById("btn2").onclick = function() {
  alert("DOM property se Hi!");
};
// Nuksaan: dobara assign karoge toh purana handler MIT jayega.
document.getElementById("btn2").onclick = function() {
  alert("Ye wala chalega, pehla gaya!");
};
</script>

Method 3 — addEventListener() (recommended, modern, exam ka hero): ek element par kai handlers jod sakte ho, purana mit-ta nahi; removeEventListener() se hata bhi sakte ho.

<button id="btn3">Click</button>
<script>
let b = document.getElementById("btn3");

function first() { alert("Pehla kaam"); }
function second() { alert("Dusra kaam"); }

b.addEventListener("click", first);
b.addEventListener("click", second);
// Ek click par DONO chalenge — yehi iski taakat hai!

b.removeEventListener("click", first);
// Ab sirf second chalega.
</script>

JavaScript string aur string methods

QUESTION

What is a JavaScript String? Explain string methods.

ANSWER

String matlab quotes ke andar likha hua text — naam, email, address sab strings hain. Single ('Hi'), double ("Hi") ya backtick (`Hi`) quotes mein likho. String characters ka ordered collection hai aur immutable hai — matlab methods original string ko badalte nahi, nayi string banakar dete hain (ye line exam mein zaroor likho).

EXAM DEFINITION

A string is a sequence of characters enclosed in quotes, used to store and manipulate text. Strings are immutable in JavaScript.

let a = 'Rohan';     // single quotes
let b = "Patil";     // double quotes
let c = `Hello ${a}`;  // backtick: ${} mein variable ghus jata hai
console.log(c);      // Hello Rohan

let s = "JavaScript";
console.log(s.length);  // 10 (property, brackets nahi)
console.log(s[0]);      // J (index 0 se start)

THEORY · Q1

What is JavaScript? Features

QUESTION

What is JavaScript? Explain its features.

ANSWER

JavaScript (JS) is the lightweight, interpreted, high-level programming language that makes web pages interactive. Created by Brendan Eich in 1995 for Netscape, it runs inside browsers today and on servers via Node.js. In one line: HTML = bones (structure), CSS = clothes (style), JavaScript = brain (behaviour).

EXAM DEFINITION

JavaScript is a lightweight, interpreted, client-side scripting language used to make web pages interactive and dynamic.

Where it is used (fix 2–3 examples): form validation (show an error if email is empty), changing content on button click, image sliders, live search suggestions, and backend APIs via Node.js. Java is a different language — the names look similar but there is no direct relation (examiners like this line).

Features — write these 7–8 points in the exam, each with a one-line meaning:

  • Lightweight and interpreted: no compilation needed; the browser reads and runs it line by line. Even small code is quick to test.
  • Client-side scripting: code runs in the user's browser, so small things need no server round-trip — form checks happen right in the browser.
  • Dynamically typed: no type annotation needed; let x = 5 can later become x = "Rohan". The type follows the value.
  • Event-driven: reacts to user actions (click, typing, mouse move) — Q4–Q5 are built on this.
  • Case-sensitive: Name and name are two different variables — watch the spelling.
  • Platform independent (in browsers): code running in Chrome also runs in Firefox/Edge.
  • Object-based + first-class functions: works with objects and arrays; functions can sit in variables and pass as arguments.
  • Huge ecosystem: React, Angular, Vue (frontend) and Node.js, Express (backend) — one language builds the full stack, which is why the subject is called Full Stack Development.

THEORY · Q4

What are JavaScript events?

QUESTION

What are JavaScript Events? Explain with examples.

ANSWER

An event is something happening in the browser — a click, a keypress, mouse movement, page load, or form submit. JavaScript listens for these happenings and instantly reacts by running a function. This is called event-driven programming (recall the Q1 feature).

EXAM DEFINITION

An event is an action or occurrence (click, keypress, load, submit) that JavaScript can detect and respond to using an event handler function.

How it works — 3 steps: 1) the event happens (user clicks a button), 2) the browser recognizes its name (click), 3) the handler function runs (greet()). Formula: Event + Element + Handler = Interaction.

Examples — 3 levels, easy to real:

// Example 1: popup on click (easiest)
<button onclick="alert('You clicked!')">Press</button>

// Example 2: change text on click
<p id="msg">Old text</p>
<button onclick="document.getElementById('msg').innerHTML = 'New text!'">
  Change
</button>
// "Old text" before, "New text!" after the click

// Example 3: check on form submit (real-life use)
<form onsubmit="return checkForm()">
  <input id="email" type="text" placeholder="Type email">
  <input type="submit" value="Send">
</form>
<script>
function checkForm() {
  let e = document.getElementById("email").value;
  if (e === "") {
    alert("Email is empty!");
    return false;   // form stops, never submits
  }
  return true;      // all good, form goes
}
</script>

THEORY · Q5

Methods of handling JavaScript events

QUESTION

Explain different methods of handling JavaScript events.

ANSWER

Event handling means deciding which function runs when an event fires and how to attach it. There are 3 methods — easy to best. The MCQ 6 answer (recommended = addEventListener()) is the last line of this answer.

Method 1 — Inline HTML attribute (easiest, oldest): write the handler inside the HTML tag.

<button onclick="sayHi()">Click</button>
<script>
function sayHi() {
  alert("Hi!");
}
</script>
// Plus: easy to write. Minus: HTML + JS mixed, one job per event.

Method 2 — DOM property (middle): grab the element in JavaScript and set its property.

<button id="btn2">Click</button>
<script>
document.getElementById("btn2").onclick = function() {
  alert("Hi via DOM property!");
};
// Minus: reassigning WIPES the old handler.
document.getElementById("btn2").onclick = function() {
  alert("Only this one runs now!");
};
</script>

Method 3 — addEventListener() (recommended, modern, exam hero): attach many handlers to one element without wiping old ones; remove them with removeEventListener().

<button id="btn3">Click</button>
<script>
let b = document.getElementById("btn3");

function first() { alert("First job"); }
function second() { alert("Second job"); }

b.addEventListener("click", first);
b.addEventListener("click", second);
// ONE click runs BOTH — that is its power!

b.removeEventListener("click", first);
// Now only second runs.
</script>

THEORY · Q6

JavaScript strings and string methods

QUESTION

What is a JavaScript String? Explain string methods.

ANSWER

A string is text inside quotes — names, emails, addresses are all strings. Write them in single ('Hi'), double ("Hi"), or backtick (`Hi`) quotes. A string is an ordered collection of characters and is immutable — methods never change the original string, they return a new string (always write this line in the exam).

EXAM DEFINITION

A string is a sequence of characters enclosed in quotes, used to store and manipulate text. Strings are immutable in JavaScript.

let a = 'Rohan';     // single quotes
let b = "Patil";     // double quotes
let c = `Hello ${a}`;  // backtick: ${} embeds a variable
console.log(c);      // Hello Rohan

let s = "JavaScript";
console.log(s.length);  // 10 (a property, no brackets)
console.log(s[0]);      // J (index starts at 0)
