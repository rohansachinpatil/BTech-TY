COURSE CONTENT / 5 UNITS

Machine Learning syllabus

Neeche syllabus.txt ke units wahi sequence mein hain. Mid-sem QB Unit 1, 2 aur 3 se hai.

UNIT 01 Introduction to Machine Learning 07 Hrs

Basics and types

Definition of Machine Learning, Definition of learning; Classification: Supervised, Unsupervised, Reinforcement, Semi-supervised learning; Output-based categories: Classification, Regression, Clustering; Difference in ML and Traditional Programming; Data, Information and Knowledge; Training, Validation and Testing data split; Applications.

UNIT 02 Machine Learning - Performance Metrics 07 Hrs

Classification metrics

Confusion Matrix, Classification Accuracy, Classification Report: Precision, Recall (Sensitivity), Support, F1 Score, AUC (Area Under ROC curve).

Regression metrics

Mean Absolute Error (MAE), Mean Square Error (MSE), R Squared (R²).

UNIT 03 Linear and Logistic Regression 07 Hrs

Linear regression

Introduction, Optimal Coefficients, Cost function, Coefficient of Determination, Dummy-data analysis, Intuition; Multivariable regression and Gradient Descent: generic gradient descent, Learning Rate, Normal Equation complexity, Complex Boundaries, Variations of Gradient Descent.

Logistic regression

Handling Classification Problems, Logistic Regression, Cost Function, Optimal Values, Derivatives, Multiclass, Complex Boundaries and Regularization, Logistic Regression from Sklearn.

UNIT 04 Decision Trees and Random Forests 07 Hrs

Trees and forests

Decision Trees, Interview-call example, Building trees, Best tree, Split feature, Continuous features, Sklearn code, Information gain, Gain Ratio, Gini Index, Overfitting, Pruning; Random Forests, Bagging, Feature Selection, Extra Trees, Regression with trees/forests, Random Forest in Sklearn.

UNIT 05 Naive Bayes, KNN and SVM 07 Hrs

Classifiers

Naive Bayes: Bayes theorem, independence assumption, discrete/continuous probability estimation, zero probabilities, implementation, text classification; KNN: introduction, feature scaling, Sklearn, cross validation, optimal K, curse of dimensionality, categorical data, pros and cons; SVM: intuition, cost function, decision boundary and C, Sklearn, non-linear boundaries, landmarks, similarity functions, multi-class, grid search, SVR.
