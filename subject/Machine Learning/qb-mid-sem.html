ASSIGNMENT 1 · Q1

Machine Learning ki definition

QUESTION

Define Machine Learning. How does it differ from traditional programming?

ANSWER

Machine Learning ka matlab hai aisa program banana jo data se khud seekhe — use har situation ka rule pehle se likhkar nahi dena padta. Arthur Samuel ki classic definition: “field of study that gives computers the ability to learn without being explicitly programmed.” Simple words mein: data input karo, model patterns dhoondhta hai, aur naye data par prediction karta hai.

FORMAL DEFINITION (TOM MITCHELL)

Task T, Performance measure P, Experience E — E ke saath T par P improve ho toh program learn kar raha hai. Example: T = spam pehchanna, P = accuracy, E = labeled emails.

Learning ka matlab yahan performance improve hona hai: jaise-jaise model zyada examples dekhta hai, uski predictions behtar hoti jaati hain. Example: spam filter ko hazaron labeled emails dikhao; wo khud seekh leta hai ki kaunse words spam ki nishaani hain. Training ke baad model naye, unseen emails par kaam karta hai — isi ko generalization kehte hain.

ASSIGNMENT 1 · Q2

Supervised vs unsupervised learning

QUESTION

State the difference between supervised and unsupervised learning in machine learning. Provide one example of each.

ANSWER

Supervised learning mein training data labeled hota hai — har input ke saath sahi answer diya hota hai, aur model input se answer tak ka mapping seekhta hai. Training ke baad model naye input ka answer predict karta hai. Example: past marks dekhkar student ka grade predict karna (input = past performance, label = final grade).

Unsupervised learning mein data unlabeled hota hai — koi sahi answer nahi diya hota. Model khud data mein groups ya structure dhoondhta hai, aur human baad mein check karta hai ki groups meaningful hain ya nahi. Example: purchase history ke basis par customers ki grouping (clustering) — pehle se koi “ye group A hai” label nahi hota.

QUESTION

Type: Supervised learning — classification. Justification 3 points mein likho:

ASSIGNMENT 1 · Q6A

Robot rewards se chalna seekhe

QUESTION

A robot learns to walk by receiving rewards or penalties. Classify into Supervised, Unsupervised, or Reinforcement Learning and justify.

ANSWER

Type: Reinforcement learning. Justification: robot ko “sahi step kaunsa hai” ye label-wise nahi bataya jata. Wo actions try karta hai (aage jhuko, pair uthao), girne par penalty aur aage badhne par reward milta hai, aur dheere-dheere aisi policy seekh leta hai jo total reward maximum kare.

RL loop 4 words mein: state → action → reward → better policy. Supervised nahi hai kyunki sahi answers ka dataset nahi hai; unsupervised nahi hai kyunki goal grouping nahi, behter actions seekhna hai. Exam mein “reward/penalty feedback” keyword zaroor likho — ye RL ki pehchaan hai.

RL ke 5 elements robot example par map karo: agent (robot), environment (floor), state (body position), action (pair uthana/jhukna), reward (aage badhne par +, girne par −). Robot ka goal total future reward maximum karna hai, isliye wo explore bhi karta hai (naye moves try) aur exploit bhi (jo kaam kiya use repeat). Ye exploration-exploitation balance RL ki khaas baat hai — supervised mein aisa kuch nahi hota.

QUESTION

Grouping customers based on purchase history without prior labels. Classify into Supervised, Unsupervised, or Reinforcement Learning and justify.

ANSWER

ASSIGNMENT 1 · Q8

ML ke chaar major types

QUESTION

Explain the four major types of Machine Learning.

ANSWER

Types supervision (kitni guidance milti hai) ke basis par bante hain. Har type ke saath uska data, goal aur ek pakka example likho:

  • Supervised learning: labeled data (input + sahi answer) se prediction seekhna. Tasks: classification, regression. Example: spam detection, grade prediction.
  • Unsupervised learning: unlabeled data mein khud structure dhoondhna. Tasks: clustering, association. Example: customer grouping, market-basket rules.
  • Reinforcement learning: reward/penalty feedback se trial-and-error mein best actions seekhna. Loop: state → action → reward → better policy. Example: game AI, robot walking.
  • Semi-supervised learning: thoda labeled + bahut saara unlabeled data milakar seekhna — labeling costly ho tab useful. Example: web page classification jahan kuch pages manually tag hain.

Iske saath output-based categories bhi likho: classification (categories), regression (numbers), clustering (groups). Classification/regression supervised mein, clustering unsupervised mein aata hai.

Har type ke 2 applications yaad rakho (exam mein example maanga jaata hai): supervised — spam filter, disease diagnosis; unsupervised — customer segments, gene grouping; RL — self-driving (lane keep + speed), warehouse robots; semi-supervised — speech recognition (thodi transcribed audio + bahut untranscribed), photo tagging. Semi-supervised ka assumption ek line mein: paas-paaskhe points mostly same class ke hote hain (smoothness), isliye thode labels door tak kaam aate hain.

ASSIGNMENT 1 · Q9

Chaar supervised algorithms aur applications

QUESTION

Explain any four supervised learning algorithms and their applications.

ANSWER

Har algorithm ke liye 2 lines likho — kaise kaam karta hai + kahan use hota hai:

  • Linear Regression: input-output ke beech best-fit line (ŷ = a + bx) se continuous value predict karta hai; least squares se coefficients nikalte hain. Application: house-price prediction, sales forecasting.
  • Logistic Regression: linear combination ko sigmoid se probability mein badalkar classification karta hai (threshold 0.5). Application: medical diagnosis (disease yes/no), email spam filtering.
  • Decision Trees: data ko feature tests (“age > 30?”) par split karte hue tree banata hai; leaf par decision hoti hai. Splitting ke liye information gain/Gini use hota hai. Application: loan approval, interview screening.
  • KNN (K-Nearest Neighbours): naye point ke sabse kareebi K neighbours dekhkar majority vote (classification) ya average (regression) leta hai; isse pehle feature scaling zaroori hai. Application: handwritten digit recognition, recommendation systems.

(Vikalp ke taur par SVM bhi likh sakte ho: classes ke beech maximum-margin boundary dhoondhta hai; application: text classification, image recognition.) Exam mein har algorithm ke saath ek application compulsory likho.

Har algorithm ka “kaise” thoda aur gehra samjho: linear regression least squares se line fit karta hai; logistic regression linear sum ko sigmoid se probability banata hai (0.5 threshold); decision tree har node par best split (information gain/Gini) chunakar leaf tak pahunchata hai; KNN mein K ki value tradeoff hai — chhota K noise pakadta hai, bada K boundaries smooth kar deta hai (cross-validation se optimal K chuno). Ye one-liners answer ko topper-level banate hain.

ASSIGNMENT 1 · Q10

Unsupervised learning ka working aur steps

QUESTION

Explain the working of Unsupervised Learning and its major steps.

ANSWER

Unsupervised learning mein teacher (labels) nahi hota — model khud data ki structure discover karta hai. Working 4 steps mein samjho:

  • Step 1 — Data collect aur prepare karo: unlabeled data ikattha karo, saaf karo (missing values, outliers), relevant features select karo aur scale karo — kyunki distance-based methods scale-sensitive hote hain.
  • Step 2 — Similarity measure chuno: decide karo “same jaisa” ka matlab kya hai — clustering ke liye distance (Euclidean), association ke liye co-occurrence/support.
  • Step 3 — Pattern discover karo: clustering (K-means jaise similar points ke groups) ya association rules (market-basket: “bread lene wale aksar butter lete hain”).
  • Step 4 — Evaluate aur interpret karo: labels nahi hain isliye domain knowledge se check karo ki groups meaningful hain (cohesion, separation), phir business action lo — jaise har customer group ke liye alag offer.

Ek line mein antar: supervised mein error = prediction vs label se milta hai; unsupervised mein quality = groups ki meaningfulness se judge hoti hai.

End-to-end example se working pakki karo (mall customers): data = age + annual income + spending score → scale karo → K-means se 5 clusters → interpret karo (ek cluster “young high-spenders”, ek “budget families”) → mall har cluster ko alag discount strategy deta hai. Association side ka example: billing data se rule “bread → butter (support 5%, confidence 70%)” — support batata hai kitni baar saath bike, confidence batata hai kitni baar rule sahi nikla. Dono hi bina labels ke nikle — yahi unsupervised ki pehchaan hai.

Exam-ready plan: 4 steps headings + mall end-to-end example + supervised-se-antar line.

ASSIGNMENT 2 · Q1

Accuracy, Precision, Recall, F1-Score

QUESTION

Define the following classification metrics and explain their importance in evaluating a machine learning model: Accuracy, Precision, Recall, F1-Score.

ANSWER

Classification model ko sirf “kitne sahi” se judge karna misleading ho sakta hai — especially jab classes unbalanced hon (jaise 95 healthy, 5 diseased: sabko healthy bolo toh bhi 95% accuracy!). Isliye chaar metrics ka role alag hai:

  • Accuracy = (TP + TN) / total. Overall sahi predictions ka fraction. Balanced data par useful; imbalanced par dhokha de sakti hai — isliye akele is par bharosa nahi karte.
  • Precision = TP / (TP + FP). “Positive bola, usme se kitne really positive?” False alarms costly hon toh precision dekho. Example: spam filter — genuine mail kabhi spam mein nahi jaana chahiye, isliye high precision chahiye.
  • Recall (Sensitivity) = TP / (TP + FN). “Asli positives mein se kitne pakde?” Miss karna costly ho toh recall dekho. Example: disease detection — koi patient chhootna nahi chahiye, isliye high recall chahiye.
  • F1-Score = 2·P·R / (P + R). Precision aur recall ka harmonic mean — dono ka balance ek number mein. Jab dono important hon aur trade-off ho, F1 dekho. Harmonic mean isliye, taaki ek bhi low ho toh score neeche khinche.

Importance ek line mein: accuracy overall picture, precision false alarms ke against, recall miss ke against, F1 dono ka balance — model select karte waqt problem ki cost ke hisaab se metric chuno.

Imbalance wala classic example hamesha yaad rakho: 95 healthy + 5 diseased mein “sab healthy” bolo toh accuracy 95% — lagta hai model great hai, par recall = 0/5 = 0! Isliye imbalanced data par accuracy dekhna mana hai; wahan precision/recall/F1 dekho. Range bhi likh lo: chaaron metrics 0–1 (ya 0–100%) mein hote hain, 1 = perfect. Aur support ka matlab: har class mein kitne samples the — bina support ke precision/recall numbers ka bharosa nahi hota (5 samples par 100% precision ka koi matlab nahi).

Exam-ready plan: 4 formulas + imbalance example + kab-kaunsa-metric mapping.

ASSIGNMENT 2 · Q2

Confusion matrix se error types pehchanna

QUESTION

Explain with an example how a confusion matrix can help identify the type of errors a classification model is making.

ANSWER

Confusion matrix predictions ko actual labels se cross karke 4 cells mein baantta hai. Disease example lo (Positive = disease hai):

  • TP (True Positive): disease hai, model ne bola hai — sahi pakda.
  • TN (True Negative): disease nahi hai, model ne nahi bola — sahi chhoda.
  • FP (False Positive): disease nahi hai phir bhi bola hai — false alarm (Type I error). Cost: bekaar mein tension aur extra tests.
  • FN (False Negative): disease hai par bola nahi — miss (Type II error). Cost: patient ka treatment chhoot gaya, sabse dangerous.

Matrix padhkar model ka behaviour samajh aata hai: agar FN zyada hain toh model conservative hai — positive bolne se darta hai, threshold kam karo ya positive class ko weight do. Agar FP zyada hain toh model over-eager hai — threshold badhao. Isi reading se decide hota hai ki threshold tune karna hai, data badhana hai ya model retrain karna hai. Bina matrix ke sirf accuracy dekhkar ye direction kabhi nahi milegi.

Hypothesis-testing se jodkar yaad rakho: H0 = “patient healthy” mano toh FP ka matlab innocent ko guilty kehna (Type I), FN ka matlab guilty ko chhod dena (Type II). Court mein Type I se bachne ke liye “beyond reasonable doubt” chahiye (high precision mindset); medical screening mein Type II se bachne ke liye har shak par test (high recall mindset). Dono errors ka cost alag hai — isliye problem dekhkar metric chuno, aur ROC/AUC curve se poore threshold range ka behaviour ek nazar mein dekho.

Exam-ready plan: 4 cells + Type I/II + threshold direction + ROC line.

ASSIGNMENT 2 · Q3 — SOLVED NUMERICAL

Disease data: chaaron metrics nikalo

QUESTION

A model tested on 100 samples (Positive = disease, Negative = no disease) gave: Predicted Positive / Actual Positive = 50, Predicted Positive / Actual Negative = 5, Predicted Negative / Actual Positive = 10, Predicted Negative / Actual Negative = 35. Evaluate Accuracy, Precision, Recall, F1-Score.

ANSWER

Pehle cells pehchano: TP = 50, FP = 5, FN = 10, TN = 35, total = 100. Phir formulas lagao:

Accuracy  = (TP + TN) / total = (50 + 35) / 100 = 0.85 = 85%
Precision = TP / (TP + FP) = 50 / (50 + 5) = 50/55 ≈ 0.909 = 90.9%
Recall    = TP / (TP + FN) = 50 / (50 + 10) = 50/60 ≈ 0.833 = 83.3%
F1-Score  = 2·P·R/(P+R) = 2(0.909)(0.833)/(0.909+0.833) ≈ 0.869 = 86.9%

Interpretation (marks wali line): precision (90.9%) recall (83.3%) se zyada hai — model positive bolne mein careful hai, lekin 10 real patients miss ho gaye (FN = 10), jo medical case mein serious hai. Isliye yahan recall improve karna priority hai — threshold kam karo ya FN par zyada penalty do.

ASSIGNMENT 2 · Q4

MAE, MSE, RMSE, R²

QUESTION

Explain MAE, MSE, RMSE, R².

ANSWER

Regression mein prediction number hota hai, isliye error = actual − predicted se metrics bante hain. Har metric error ko alag nazariye se dekhta hai:

  • MAE = (1/n)Σ|y − ŷ|. Average absolute galti, original units mein (jaise “average 10 marks ka error”). Outliers se kam affect hota hai — robust metric. Typical error size batata hai.
  • MSE = (1/n)Σ(y − ŷ)². Errors square hone se badi galtiyon ko zyada penalty milti hai (10 ka error 100 ban jaata hai). Training mein optimize karna easy hai kyunki differentiable hai — isliye loss function mein MSE use hota hai.
  • RMSE = √MSE. MSE ka square root — wapas original units mein, taaki interpret karna aasaan ho (“typical large-error scale”). Badi errors par sensitive hai; model comparison mein standard metric.
  • R² = 1 − SSres/SStot. Model ne output ki kitni variance explain ki — 0 se 1 tak (1 = perfect, 0 = mean predictor jitna). Alag units/scales wale models compare karne mein useful hai. Negative R² ka matlab model mean se bhi kharab hai.

Regression experiment design karo

QUESTION

Design an experiment to evaluate the performance of a regression model using MAE, RMSE, and R² metrics. What steps would you include and why?

ANSWER

Experiment ka goal: model unseen data par kitna achha hai, ye honestly measure karna. Har step ke saath “why” likho — wahi design ka justification hai:

  • Step 1 — Data split karo (train/validation/test, jaise 70/15/15): taaki model unseen data par test ho. Bina split ke model ratt-fication (overfitting) chhupa lega — training error hamesha optimistic hota hai.
  • Step 2 — Baseline fix karo (mean predictor): har input par training mean predict karo. Isse pata chalta hai model baseline se genuinely better hai ya nahi (R² isi se compare hota hai).
  • Step 3 — Train par fit, validation par tune karo: hyperparameters (jaise regularization strength, tree depth) validation MAE/RMSE se chuno. Test set ko tuning mein bilkul mat chhuo — wo final exam hai.
  • Step 4 — Test par teenon metrics report karo: MAE (typical error size), RMSE (badi galtiyon ka penalty), R² (variance explained). Teenon milkar poori picture dete hain — ek metric se model chhupta hai.
  • Step 5 — Residuals check karo: errors ko predictions ke against plot karo. Random spread = model theek; koi pattern/funnel = kuch missing hai (non-linearity, outlier) — model wapas sudharo.

Exam mein 5 steps headings banakar likho; har heading ke neeche one-line “why” — design + justification dono cover honge.

Metrics ko padhne ka guide bhi likh do (experiment ka conclusion kaise likhein): MAE chhota + RMSE uske kareeb = errors uniform aur model stable; RMSE MAE se bahut bada = kuch outliers ya badi misses hain, un cases ko alag analyse karo; R² 0.9 ke paas = variance mostly explained, 0.5 se neeche = features ya model badlo. Aur reliability ke liye single split ki jagah k-fold cross-validation use karo — data ke K tukde, har tukda ek baar test, metrics ka average lo — taaki lucky/unlucky split ka dhokha na ho.

ASSIGNMENT 3 · Q3

Line of best fit kaise milti hai

QUESTION

Explain how a line of best fit is determined in linear regression.

ANSWER

Best fit wo line hai jo squared errors ka sum (SSE) minimum kare — ise least squares method kehte hain. Poora logic 4 steps mein:

  • Step 1 — Error define karo: har point ka error = actual − predicted, yani e = y − (a + bx). Seedha sum loge toh positive-negative cancel ho jayenge, isliye square karte hain.
  • Step 2 — SSE likho: SSE = Σ(y − a − bx)². Ye a aur b ka function hai; goal iska minimum dhoondhna hai.
  • Step 3 — Derivative zero karo: SSE ka a aur b ke respect mein partial derivative lekar zero ke barabar rakho. Isse 2 equations (normal equations) milti hain.
  • Step 4 — Solve karo: inhi se nikalte hain b = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² aur a = ȳ − bx̄ — wahi formulas jo Q2 mein use kiye.

Cost function J = (1/2n)Σ(ŷ−y)² isi SSE ka scaled form hai — gradient descent isi J ko step-by-step minimize karta hai (bade data par direct formula ki jagah). Aur ek property yaad rakho: best-fit line hamesha point (x̄, ȳ) se guzarti hai — Q2 mein (5, 6.25) check karke dekho: 1.5 + 0.95×5 = 6.25. Exam mein ye verification line likhna impressive lagta hai.

Gradient descent ka update rule ek line mein: θ := θ − α·∇J — θ parameters hain, α learning rate (kadam kitna bada), ∇J slope ki direction. α bahut bada → overshoot/diverge; bahut chhota → training bahut slow. Normal equation (direct formula) chhote data par exact aur fast hai, par bada data par costly — isliye wahan gradient descent. Dono ka target ek hi hai: minimum SSE/J.

Exam-ready plan: 4 steps (error→SSE→derivative→solve) + J + α rule + mean-point check.

Multicollinearity ka asar

QUESTION

Explain how multicollinearity affects a multiple linear regression model.

ANSWER

Multicollinearity ka matlab: multiple regression ke do ya zyada input features aapas mein strongly correlated hain. Classic example: “total marks” aur “average marks” dono features hon — ek badhe toh doosra apne aap badhta hai, model confuse ho jaata hai ki credit kisko de.

Asar 3 levels par samjho:

  • Coefficients unstable: thoda data badlo, coefficient values bahut hil jaati hain — kabhi positive, kabhi negative. Model unreliable lagta hai.
  • Interpretation kharab: standard errors inflate ho jaati hain, toh p-values bade aate hain — important features bhi “insignificant” lagne lagte hain. “Kis feature ka asar kitna” ye sawal ka jawab nahi milta.
  • Prediction par kam asar: overall predictions phir bhi theek aa sakte hain — problem explanation aur feature selection mein hai, prediction mein utni nahi.

Fix (exam mein ek line): correlated features mein se ek hatao (correlation matrix/VIF se detect karke), ya regularization (Ridge/Lasso) use karo jo coefficients ko stable rakhta hai.

Detection aur fix thoda aur detail mein: correlation matrix mein feature-pairs ke 0.8–0.9+ values dhoondho; VIF (Variance Inflation Factor) 5–10 se upar ho toh problem pakki. Fix ke 3 raste: (1) ek correlated feature drop karo (domain sense se jo kam useful ho), (2) dono ko combine karke ek feature banao (jaise ratio), (3) Ridge (coefficients shrink karta hai) ya Lasso (kuch coefficients ko zero karke feature select bhi karta hai) lagao. Exam mein “drop ya regularize” likhna kaafi hai, par VIF ka naam aaye toh detection wala part strong lagta hai.

ASSIGNMENT 3 · Q6

Sigmoid function aur uska role

QUESTION

Explain the sigmoid function and its significance in logistic regression.

ANSWER

Sigmoid function: σ(z) = 1 / (1 + e−z). Iske 3 properties yaad rakho:

  • Squash: kisi bhi real number (chahe −1000 ya +1000) ko 0–1 ke beech dabaa deta hai. z → −∞ par output → 0, z → +∞ par → 1.
  • S-shape: beech mein (z = 0 par) output exactly 0.5; curve smooth aur differentiable hai — isliye gradient-based training possible hai.
  • Threshold: 0.5 ke upar class 1, neeche class 0 — decision boundary ban jaata hai.

Significance in logistic regression: linear part z = w·x + b koi bhi value de sakta hai (−∞ se +∞), jo probability nahi ban sakti. Sigmoid isi z ko probability mein badalta hai: P(class=1) = σ(w·x + b). Bina sigmoid ke logistic regression sirf ek line hoti; sigmoid hi use classifier banata hai. (Gehri baat: isi S-shape ki wajah se MSE loss non-convex ho jaata hai, isliye log-loss use hota hai.)

Defining Machine Learning

QUESTION

Define Machine Learning. How does it differ from traditional programming?

ANSWER

Machine Learning means building programs that learn from data themselves — the rules for every situation are not written in advance. Arthur Samuel's classic definition: “field of study that gives computers the ability to learn without being explicitly programmed.” Simply: feed data in, the model finds patterns, and predicts on new data.

Example: show a spam filter thousands of labeled emails; it learns on its own which words signal spam. After training, the model works on new, unseen emails — this is called generalization.

ASSIGNMENT 1 · Q2

Supervised vs unsupervised learning

QUESTION

State the difference between supervised and unsupervised learning in machine learning. Provide one example of each.

ANSWER

In supervised learning the training data is labeled — every input comes with the correct answer, and the model learns the mapping from input to answer. After training, the model predicts answers for new inputs. Example: predicting a student's grade from past marks (input = past performance, label = final grade).

In unsupervised learning the data is unlabeled — no correct answers are given. The model itself finds groups or structure in the data, and humans later check whether the groups are meaningful. Example: grouping customers by purchase history (clustering) — with no pre-decided “this is group A” label.

ASSIGNMENT 2 · Q1

Accuracy, Precision, Recall, F1-Score

QUESTION

Define the following classification metrics and explain their importance in evaluating a machine learning model: Accuracy, Precision, Recall, F1-Score.

ANSWER

Judging a classifier only by “how many correct” can mislead — especially with unbalanced classes (e.g. 95 healthy, 5 diseased: calling everyone healthy still gives 95% accuracy!). Each of the four metrics has a distinct role:

  • Accuracy = (TP + TN) / total. Fraction of overall correct predictions. Useful on balanced data; deceptive on imbalanced data — so never rely on it alone.
  • Precision = TP / (TP + FP). “Of all predicted positive, how many are really positive?” Watch it when false alarms are costly. Example: spam filter — genuine mail must never land in spam, so high precision is needed.
  • Recall (Sensitivity) = TP / (TP + FN). “Of all real positives, how many were caught?” Watch it when missing is costly. Example: disease detection — no patient should be missed, so high recall is needed.
  • F1-Score = 2·P·R / (P + R). Harmonic mean of precision and recall — both balanced in one number. Use it when both matter and trade off. It is harmonic (not simple average) so that a low value on either side drags the score down.

Importance in one line: accuracy for the overall picture, precision against false alarms, recall against misses, F1 for the balance of both — choose the metric according to the problem's cost.

Always remember the classic imbalance example: with 95 healthy + 5 diseased, “call everyone healthy” gives 95% accuracy — the model looks great, but recall = 0/5 = 0! So on imbalanced data, looking at accuracy is forbidden; look at precision/recall/F1. Also note the ranges: all four metrics live in 0–1 (or 0–100%), 1 = perfect. And the meaning of support: how many samples each class had — without support, precision/recall numbers can't be trusted (100% precision on 5 samples means nothing).

ASSIGNMENT 2 · Q2

Identifying error types with a confusion matrix

QUESTION

Explain with an example how a confusion matrix can help identify the type of errors a classification model is making.

ANSWER

A confusion matrix crosses predictions with actual labels into 4 cells. Take the disease example (Positive = has disease):

  • TP (True Positive): has disease, model flagged it — caught right.
  • TN (True Negative): no disease, model stayed silent — left out right.
  • FP (False Positive): no disease but flagged — false alarm (Type I error). Cost: needless worry and extra tests.
  • FN (False Negative): has disease but missed — miss (Type II error). Cost: the patient's treatment is missed — the most dangerous.

Reading the matrix reveals the model's behaviour: many FNs mean the model is conservative — afraid of saying positive, so lower the threshold or weight the positive class. Many FPs mean the model is over-eager — raise the threshold. This reading decides whether to tune the threshold, add data, or retrain the model. Mere accuracy could never give this direction.

Connect it to hypothesis testing to remember: take H0 = “patient healthy”; then FP means calling the innocent guilty (Type I), FN means letting the guilty go (Type II). Courts demand “beyond reasonable doubt” to avoid Type I (high-precision mindset); medical screening tests every suspicion to avoid Type II (high-recall mindset). Both errors cost differently — so pick the metric by the problem, and view the whole threshold range at a glance with the ROC/AUC curve.

Exam-ready plan: 4 cells + Type I/II + threshold direction + ROC line.

Disease data: all four metrics

QUESTION

A model tested on 100 samples (Positive = disease, Negative = no disease) gave: Predicted Positive / Actual Positive = 50, Predicted Positive / Actual Negative = 5, Predicted Negative / Actual Positive = 10, Predicted Negative / Actual Negative = 35. Evaluate Accuracy, Precision, Recall, F1-Score.

Precision = TP / (TP + FP) = 50 / (50 + 5) = 50/55 ≈ 0.909 = 90.9%
Recall    = TP / (TP + FN) = 50 / (50 + 10) = 50/60 ≈ 0.833 = 83.3%

ASSIGNMENT 2 · Q4

MAE, MSE, RMSE, R²

QUESTION

Explain MAE, MSE, RMSE, R².

ANSWER

In regression the prediction is a number, so metrics are built from error = actual − predicted. Each metric views the error differently:

  • MAE = (1/n)Σ|y − ŷ|. Average absolute error, in original units (e.g. “average error of 10 marks”). Less affected by outliers — a robust metric. Tells typical error size.
  • MSE = (1/n)Σ(y − ŷ)². Squaring punishes large errors more (an error of 10 becomes 100). Easy to optimize in training because it is differentiable — hence used as the loss function.
  • RMSE = √MSE. Square root of MSE — back in original units for easy interpretation (“typical large-error scale”). Sensitive to large errors; the standard metric for model comparison.
  • R² = 1 − SSres/SStot. How much output variance the model explains — 0 to 1 (1 = perfect, 0 = as good as the mean predictor). Useful for comparing models across scales. Negative R² means worse than the mean.

Feel the difference with an outlier demo: errors [1, 1, 1, 10] give MAE = 13/4 = 3.25, but MSE = (1+1+1+100)/4 = 25.75 and RMSE ≈ 5.07 — one big error drags RMSE to nearly double the MAE. Hence: MAE for typical performance, RMSE when big mistakes scare you. Understand R²'s parts: SSres = the model's leftover error (smaller = better), SStot = the data's total spread; the more spread the model explains, the closer R² gets to 1.

ASSIGNMENT 2 · Q5

Designing a regression experiment

QUESTION

Design an experiment to evaluate the performance of a regression model using MAE, RMSE, and R² metrics. What steps would you include and why?

ANSWER

The experiment's goal: honestly measure how good the model is on unseen data. Write the “why” with every step — that is the design's justification:

  • Step 1 — Split data (train/validation/test, e.g. 70/15/15): so the model is tested on unseen data. Without a split, memorization (overfitting) stays hidden — training error is always optimistic.
  • Step 2 — Fix a baseline (mean predictor): predict the training mean for every input. Shows whether the model is genuinely better than the trivial option (R² compares against exactly this).
  • Step 3 — Fit on train, tune on validation: choose hyperparameters (regularization strength, tree depth) by validation MAE/RMSE. Never touch the test set during tuning — it is the final exam.
  • Step 4 — Report all three metrics on test: MAE (typical error size), RMSE (big-error penalty), R² (variance explained). All three together give the full picture — one metric lets the model hide.
  • Step 5 — Check residuals: plot errors against predictions. Random spread = model fine; any pattern/funnel = something missing (non-linearity, outlier) — go back and improve the model.

In the exam, write the 5 steps as headings; one-line “why” under each covers both design and justification.

Also write a guide for reading the metrics (how to conclude the experiment): small MAE with RMSE close to it = uniform errors and a stable model; RMSE much bigger than MAE = some outliers or big misses — analyse those cases separately; R² near 0.9 = variance mostly explained, below 0.5 = change features or model. And for reliability, use k-fold cross-validation instead of a single split — K pieces of data, each tested once, metrics averaged — so no lucky/unlucky split can fool you.

Actual vs predicted: MAE and RMSE

QUESTION

Given actual values [100, 200, 150] and predicted values [110, 190, 160], calculate the MAE and RMSE.

ANSWER

First find each point's absolute error, then apply the formulas:

Errors: |100−110| = 10, |200−190| = 10, |150−160| = 10
MAE  = (10 + 10 + 10) / 3 = 30/3 = 10
MSE  = (10² + 10² + 10²) / 3 = 300/3 = 100
RMSE = √100 = 10

Here all three errors equal 10, so MAE and RMSE both come to 10. General rule to remember: RMSE is always ≥ MAE — equal only when all errors are identical, otherwise RMSE is larger because squaring amplifies big mistakes.

Comment on scale too (it strengthens interpretation): on values in the ~100–200 range, an average error of 10 is ≈ 6–7% relative error — a decent model. The same error on 10–20 range data would be considered terrible. So always read MAE/RMSE in the context of the data's scale, and use R² when comparing across different scales.

ASSIGNMENT 3 · Q1

Linear regression + role of slope and intercept

QUESTION

Define linear regression. What is the role of the slope and intercept?

ANSWER

Linear regression finds a straight-line relation between input X and continuous output Y: ŷ = a + bx. “Linear” means linear in the features — the line passes closest to the data points (via least squares). It is used both for prediction and for understanding relationships.

  • Slope (b): how much Y changes per 1-unit rise in X — the strength and direction. Positive slope = they rise together (study↔marks); negative = opposite (price↔demand); near zero ≈ no linear relation.
  • Intercept (a): where the line cuts the Y-axis at X = 0 — the starting level / baseline value. It may lack practical meaning (base marks at zero study hours), but it is needed to fix the line.

Fix it with an example: in the model ŷ = 30 + 5x (X = hours, Y = marks), each extra hour adds ~5 marks (slope = rate), with a base of 30 marks at zero hours (intercept = starting point). In the exam, definitely write: slope = “rate of change”, intercept = “baseline”.

Also write a prediction demo: at x = 10 hours, ŷ = 30 + 50 = 80 marks — that is the model's use. But add the caution: it is trustworthy only inside the training range (extrapolation is risky — 530 marks at 100 hours is absurd), and slope shows correlation, not proven causation (marks rose with hours, but hours need not be the only cause).

ASSIGNMENT 3 · Q3

How the best-fit line is found

QUESTION

Explain how a line of best fit is determined in linear regression.

ANSWER

The best-fit line minimizes the sum of squared errors (SSE) — the least squares method. The full logic in 4 steps:

  • Step 1 — Define error: each point's error = actual − predicted, i.e. e = y − (a + bx). Errors are squared because a plain sum would let positives and negatives cancel.
  • Step 2 — Write SSE: SSE = Σ(y − a − bx)². This is a function of a and b; the goal is finding its minimum.
  • Step 3 — Zero the derivatives: take partial derivatives of SSE w.r.t. a and b and set them to zero. This gives 2 equations (normal equations).
  • Step 4 — Solve: out come b = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² and a = ȳ − bx̄ — the same formulas used in Q2.

The cost function J = (1/2n)Σ(ŷ−y)² is this SSE in scaled form — gradient descent minimizes exactly this J step by step (used instead of the direct formula on big data). And remember one property: the best-fit line always passes through (x̄, ȳ) — in Q2, (5, 6.25): check 1.5 + 0.95×5 = 6.25. Writing this verification line looks impressive in the exam.

The gradient descent update rule in one line: θ := θ − α·∇J — θ are the parameters, α is the learning rate (how big each step is), ∇J is the slope direction. Too big an α → overshoot/diverge; too small → painfully slow training. The normal equation (direct formula) is exact and fast on small data but costly on big data — hence gradient descent there. Both target the same thing: minimum SSE/J.

ASSIGNMENT 3 · Q4

Effect of multicollinearity

QUESTION

Explain how multicollinearity affects a multiple linear regression model.

ANSWER

Multicollinearity means two or more input features of a multiple regression are strongly correlated with each other. Classic example: both “total marks” and “average marks” as features — when one rises, the other rises automatically, and the model gets confused about whom to credit.

Effects at 3 levels:

  • Unstable coefficients: small data changes swing coefficient values wildly — sometimes positive, sometimes negative. The model looks unreliable.
  • Broken interpretation: standard errors inflate, so p-values come out large — even important features look “insignificant”. The question “how much does each feature matter” gets no answer.
  • Little effect on prediction: overall predictions may still be fine — the problem lies in explanation and feature selection, not so much in prediction.

Fix (one exam line): drop one of the correlated features (detect via correlation matrix/VIF), or use regularization (Ridge/Lasso) which keeps coefficients stable.

Detection and fixes in a bit more detail: hunt for 0.8–0.9+ values in the correlation matrix; VIF (Variance Inflation Factor) above 5–10 confirms the problem. Three ways out: (1) drop one correlated feature (whichever makes less domain sense), (2) combine both into one feature (e.g. a ratio), (3) apply Ridge (shrinks coefficients) or Lasso (zeroes some coefficients, selecting features too). Writing “drop or regularize” suffices in the exam, but naming VIF strengthens the detection part.

Exam-ready plan: example pair + 3 effects + detection (VIF) + 3 fixes.

ASSIGNMENT 3 · Q6

Sigmoid function and its role

QUESTION

Explain the sigmoid function and its significance in logistic regression.

ANSWER

Sigmoid function: σ(z) = 1 / (1 + e−z). Remember 3 properties:

  • Squash: squeezes any real number (even −1000 or +1000) into 0–1. Output → 0 as z → −∞, → 1 as z → +∞.
  • S-shape: exactly 0.5 in the middle (z = 0); the curve is smooth and differentiable — hence gradient-based training is possible.
  • Threshold: above 0.5 → class 1, below → class 0 — a decision boundary is formed.

Significance in logistic regression: the linear part z = w·x + b can be anything (−∞ to +∞), which cannot be a probability. Sigmoid converts this z into a probability: P(class=1) = σ(w·x + b). Without sigmoid, logistic regression would be just a line; sigmoid is what makes it a classifier. (Deeper point: because of this S-shape, the MSE loss becomes non-convex here, which is why log-loss is used.)

ASSIGNMENT 3 · Q7

Logistic vs linear regression

QUESTION

Define logistic regression. How is it different from linear regression?

ANSWER

Logistic regression converts the linear combination z = w·x + b into a probability via sigmoid and classifies: P = σ(z), then a class label from the 0.5 threshold. The name contains “regression” because inside there is a weighted sum like linear regression — but the output is a class.

Also understand the loss-function difference (it can become a 2-mark question): in linear regression MSE is convex — gradient descent reaches the global minimum directly. In logistic regression, after sigmoid the MSE turns non-convex (danger of local minima), so log-loss / cross-entropy is used instead, which is convex: probability near 1 for the right class → loss ≈ 0, confident wrong prediction → huge loss. The decision boundary is linear in both (the probability = 0.5 line in logistic), but the output means different things — value vs class.
