ASSIGNMENT 1 · UNIT I / Q1

Machine Learning kya hai? Traditional programming se farq

Machine Learning ka matlab hai aisa program banana jo data se khud seekhe — use har situation ka rule pehle se likhkar nahi dena padta. Arthur Samuel ki classic definition: “field of study that gives computers the ability to learn without being explicitly programmed.” Simple words mein: data input karo, model patterns dhoondhta hai, aur naye data par prediction karta hai.

Learning ka matlab yahan performance improve hona hai: jaise-jaise model zyada examples dekhta hai, uski predictions behtar hoti jaati hain. Example: spam filter ko hazaron labeled emails dikhao; wo khud seekh leta hai ki kaunse words spam ki nishaani hain.

ASSIGNMENT 1 · UNIT I / Q3–Q5

Data, information aur knowledge

Teenon ko ek school example se samjho. Data raw facts hain — jaise har student ke har subject ke marks ki list. Iska apne aap mein koi decision value nahi hai.

Jab data ko process karke context diya jata hai, wo information ban jaata hai — jaise “Class 10-B ka maths average 72% hai, jo pichhle term se 5% kam hai.” Ab ye baat samajh mein aati hai aur compare ho sakti hai.

Jab information ko experience aur reasoning ke saath jodkar decision liya jata hai, wo knowledge hai — jaise “maths average gir raha hai, isliye extra practice tests aur weak topics par revision plan karte hain.” Knowledge action mein badalta hai.

EXAM DEFINITIONS

Data: raw facts and figures. Information: processed, meaningful data. Knowledge: information combined with experience to guide decisions.

Scenarios ko ML type mein classify karo

Scenario dekhkar 3 sawaal poochho: (1) kya sahi answers (labels) available hain? (2) kya goal prediction hai ya grouping? (3) kya reward/penalty se seekhna hai? Isse type turant pakda jaata hai.

  • Spam email detection → Supervised (classification). Emails pehle se “spam / not spam” labeled hote hain; model naye email ka label predict karta hai. Justification: labeled training data + categorical output.
  • Robot rewards/penalties se chalna seekhe → Reinforcement learning. Koi sahi answer nahi diya jata; robot actions try karta hai aur reward/penalty se policy improve karta hai.

  • Game AI khud se khelkar improve kare → Reinforcement learning (self-play). Outcomes (jeet/haar) reward ki tarah kaam karte hain; labelled dataset nahi hota.

Exam tip: sirf type ka naam nahi, ek-line justification zaroor likho — “labels available hain, isliye supervised” jaisi line hi marks dilati hai.

Supervised algorithms aur unsupervised working

Chaar supervised algorithms aur applications:

ASSIGNMENT 2 · UNIT II / Q1–Q2

Accuracy, Precision, Recall, F1-Score

Classification model ko sirf “kitne sahi” se judge karna misleading ho sakta hai — especially jab classes unbalanced hon (jaise 95 healthy, 5 diseased). Isliye chaar metrics ka role alag hai:

  • Accuracy = (TP + TN) / total. Overall sahi predictions ka fraction. Balanced data par useful; imbalanced par dhokha de sakti hai.
  • Precision = TP / (TP + FP). “Positive bola, usme se kitne really positive?” False alarms kam karne hain toh precision dekho (spam filter — genuine mail spam mein na jaye).
  • Recall (Sensitivity) = TP / (TP + FN). “Asli positives mein se kitne pakde?” Miss karna costly ho toh recall dekho (disease detection — koi patient chhoote nahi).
  • F1-Score = 2·P·R / (P + R). Precision aur recall ka harmonic mean — dono ka balance ek number mein. Jab dono important hon, F1 dekho.

Confusion matrix se error types kaise padhein

Matrix ki 4 cells: TP (disease hai, bola hai), TN (nahi hai, bola nahi), FP (nahi hai phir bola hai — false alarm, Type I error), FN (hai par bola nahi — miss, Type II error). Example: agar FN zyada hain toh model conservative hai — positive bolne se darta hai; agar FP zyada hain toh model over-eager hai. Isi reading se pata chalta hai ki threshold badhana hai ya model retrain karna hai.

ASSIGNMENT 2 · UNIT II / Q3 — SOLVED NUMERICAL

Disease data: Accuracy, Precision, Recall, F1

Given: TP = 50, FP = 5, FN = 10, TN = 35, total = 100.

Accuracy  = (TP + TN) / total = (50 + 35) / 100 = 0.85 = 85%
Precision = TP / (TP + FP) = 50 / (50 + 5) = 50/55 ≈ 0.909 = 90.9%
Recall    = TP / (TP + FN) = 50 / (50 + 10) = 50/60 ≈ 0.833 = 83.3%
F1-Score  = 2·P·R/(P+R) = 2(0.909)(0.833)/(0.909+0.833) ≈ 0.869 = 86.9%

Interpretation ek line mein: precision (90.9%) recall (83.3%) se zyada hai — model positive bolne mein careful hai, lekin 10 real patients miss ho gaye (FN = 10), jo medical case mein serious hai. Isliye yahan recall improve karna priority hai.

ASSIGNMENT 2 · UNIT II / Q4–Q5

MAE, MSE, RMSE, R²

Regression mein prediction number hota hai, isliye error = |actual − predicted| se metrics bante hain:

  • MAE = (1/n)Σ|y − ŷ|. Average absolute galti, original units mein. Outliers se kam affect hota hai — robust metric.
  • MSE = (1/n)Σ(y − ŷ)². Errors square hone se badi galtiyon ko zyada penalty milti hai. Training mein optimize karna easy (differentiable).
  • RMSE = √MSE. MSE ka square root — wapas original units mein, taaki interpret karna aasaan ho. Badi errors par sensitive.
  • R² = 1 − SSres/SStot. Model ne output ki kitni variance explain ki (0 se 1; 1 = perfect). Alag units/scales wale models compare karne mein useful.

Regression experiment design karo (steps + why)

  • Step 1 — Data split karo (train/validation/test): taaki model unseen data par test ho, rattafication (overfitting) pakda jaye.
  • Step 2 — Baseline fix karo: jaise mean predictor; isse pata chalta hai model baseline se better hai ya nahi.
  • Step 3 — Train par fit, validation par tune karo: hyperparameters validation MAE/RMSE se chuno, test ko untouched rakho.
  • Step 4 — Teenon metrics report karo: MAE (typical error size), RMSE (badi galtiyon ka penalty), R² (variance explained) — teeno milkar poori picture dete hain.
  • Step 5 — Residuals check karo: errors randomly spread hain ya pattern hai; pattern matlab model mein kuch missing hai.

ASSIGNMENT 3 · UNIT III / Q1

Linear regression + slope aur intercept ka role

Linear regression input X aur continuous output Y ke beech seedhi line ka rishta dhoondhta hai: ŷ = a + bx. Goal: aisi line jo data points ke sabse kareeb se guzre.

  • Slope (b): X mein 1 unit badhotri par Y mein kitna badlav — rishton ki strength aur direction. Positive slope = saath badhte hain; zero ≈ koi linear rishta nahi.
  • Intercept (a): X = 0 par line Y-axis ko kahan kaat-ti hai — starting level / baseline value.

Example: agar padhai ke hours (X) se marks (Y) ka model ŷ = 30 + 5x hai, toh har extra hour ~5 marks badhata hai (slope), aur zero hours par base 30 marks (intercept).

ASSIGNMENT 3 · UNIT III / Q2–Q3 — SOLVED NUMERICAL

Regression equation + line of best fit

Given: X = [2, 4, 6, 8], Y = [3, 7, 5, 10]. Formula: b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)², a = ȳ − bx̄.

x-mean = (2+4+6+8)/4 = 5,  y-mean = (3+7+5+10)/4 = 6.25
x-dev:  −3, −1, +1, +3        → squares: 9+1+1+9 = 20
y-dev:  −3.25, +0.75, −1.25, +3.75
products: 9.75 − 0.75 − 1.25 + 11.25 = 19.0
b = 19/20 = 0.95
a = 6.25 − 0.95×5 = 6.25 − 4.75 = 1.5
Equation: ŷ = 1.5 + 0.95x

Line of best fit kaise milti hai: best fit wo line hai jo squared errors ka sum (SSE) minimum kare — ise least squares method kehte hain. Errors square isliye karte hain taaki positive-negative cancel na hon aur badi galtiyon ko zyada penalty mile. Upar wale formulas isi minimization se nikalte hain (SSE ka derivative zero karke). Cost function J = (1/2n)Σ(ŷ−y)² isi SSE ka scaled form hai — gradient descent isi ko minimize karta hai.

Multicollinearity + MAE/RMSE repeat

Multicollinearity ka matlab: multiple regression ke do ya zyada input features aapas mein strongly correlated hain (jaise “total marks” aur “average marks” dono features hon). Asar:

  • Coefficients unstable ho jaate hain — thoda data badlo, values bahut hil jaati hain.
  • Kis feature ka asar kitna hai, ye interpret karna mushkil ho jaata hai (standard errors badh jaati hain).
  • Prediction par asar kam pad sakta hai, par explanation aur feature selection bigad jaata hai.
  • Fix: correlated features mein se ek hatao, ya regularization (Ridge/Lasso) use karo.

ASSIGNMENT 3 · UNIT III / Q6–Q7

Sigmoid + logistic vs linear regression

Sigmoid function: σ(z) = 1 / (1 + e−z). Ye kisi bhi real number ko 0–1 ke beech dabaa deta hai (squash karta hai) — S-shape curve, beech mein 0.5. Significance: logistic regression linear combination z = w·x + b ko isi se probability mein badalta hai; 0.5 threshold se class decide hoti hai (≥ 0.5 → class 1).

ASSIGNMENT 1 · UNIT I / Q1

What is Machine Learning? How it differs from traditional programming

Machine Learning means building programs that learn from data themselves — the rules for every situation are not written in advance. Arthur Samuel's classic definition: “field of study that gives computers the ability to learn without being explicitly programmed.” Simply: feed data in, the model finds patterns, and predicts on new data.

Learning here means improving performance: as the model sees more examples, its predictions keep getting better. Example: show a spam filter thousands of labeled emails; it learns on its own which words signal spam.

Do write one line in the exam: in traditional programming the output comes from data and rules; in ML the rules (model) come from data and sample outputs.

ASSIGNMENT 1 · UNIT I / Q2

Supervised vs unsupervised learning

In supervised learning the training data is labeled — every input comes with the correct answer, and the model learns the mapping from input to answer. Example: predicting a student's grade from past marks (input = past performance, label = final grade).

In unsupervised learning the data is unlabeled — no correct answers are given. The model itself finds groups or structure in the data. Example: grouping customers by purchase history (clustering) — there is no pre-decided “this is group A” label.

ASSIGNMENT 1 · UNIT I / Q3–Q5

Data, information, and knowledge

Understand all three through one school example. Data are raw facts — e.g. the list of every student's marks in every subject. On its own it has no decision value.

When data is processed and given context, it becomes information — e.g. “Class 10-B's maths average is 72%, down 5% from last term.” Now it is understandable and comparable.

When information is combined with experience and reasoning to take a decision, it is knowledge — e.g. “the maths average is falling, so plan extra practice tests and revision of weak topics.” Knowledge turns into action.

EXAM DEFINITIONS

Data: raw facts and figures. Information: processed, meaningful data. Knowledge: information combined with experience to guide decisions.

Memory hook: Data = raw material; Information = the cooked dish; Knowledge = the recipe experience that makes the next dish better.

ASSIGNMENT 1 · UNIT I / Q4–Q6

Classifying scenarios into ML types

Looking at a scenario, ask 3 questions: (1) are correct answers (labels) available? (2) is the goal prediction or grouping? (3) is learning through reward/penalty? The type is caught at once.

  • Spam email detection → Supervised (classification). Emails are pre-labeled “spam / not spam”; the model predicts the label of new mail. Justification: labeled training data + categorical output.
  • Robot learning to walk via rewards/penalties → Reinforcement learning. No correct answers are given; the robot tries actions and improves its policy from rewards/penalties.
  • Grouping customers without labels → Unsupervised (clustering). Groups are unknown beforehand; they emerge from similarity in purchase history.
  • Predicting grades from past performance → Supervised (regression or classification). Past data with known grades acts as labels. Predicting marks is regression; pass/fail is classification.
  • Game AI improving by self-play → Reinforcement learning (self-play). Outcomes (win/loss) act as rewards; there is no labeled dataset.

Exam tip: don't write only the type name — always add a one-line justification like “labels are available, hence supervised”; that line earns the marks.

ASSIGNMENT 1 · UNIT I / Q9–Q10

Supervised algorithms and unsupervised working

Four supervised algorithms with applications:

  • Linear Regression: predicts a continuous value (house price, marks). Application: sales forecasting.
  • Logistic Regression: despite the name it classifies (pass/fail, disease yes/no). Application: medical diagnosis.
  • Decision Trees: decides by splitting data on feature tests. Application: loan approval, interview screening.
  • KNN / SVM: KNN votes via neighbours; SVM finds the best-margin boundary. Application: handwritten digit recognition, text classification.

Working of unsupervised learning, major steps:

  • Step 1 — Collect and prepare data: clean unlabeled data, select/scale features.
  • Step 2 — Choose a similarity measure: e.g. distance (clustering) or co-occurrence (association).
  • Step 3 — Discover patterns: clustering (K-means style groups) or association rules (market-basket: “butter with bread”).
  • Step 4 — Evaluate and interpret: check with domain knowledge whether the groups are meaningful.

ASSIGNMENT 2 · UNIT II / Q1–Q2

Accuracy, Precision, Recall, F1-Score

Judging a classifier only by “how many correct” can mislead — especially with unbalanced classes (e.g. 95 healthy, 5 diseased). Each of the four metrics has a distinct role:

  • Accuracy = (TP + TN) / total. Fraction of overall correct predictions. Useful on balanced data; deceptive on imbalanced data.
  • Precision = TP / (TP + FP). “Of all predicted positive, how many are really positive?” Watch it when false alarms hurt (spam filter — genuine mail must not land in spam).
  • Recall (Sensitivity) = TP / (TP + FN). “Of all real positives, how many were caught?” Watch it when missing hurts (disease detection — no patient missed).
  • F1-Score = 2·P·R / (P + R). Harmonic mean of precision and recall — both balanced in one number. Use it when both matter.

Reading error types from a confusion matrix

The 4 cells: TP (has disease, flagged), TN (healthy, not flagged), FP (healthy but flagged — false alarm, Type I error), FN (diseased but missed — Type II error). Example: many FNs mean the model is conservative — afraid of saying positive; many FPs mean it is over-eager. This reading tells whether to move the threshold or retrain the model.

ASSIGNMENT 2 · UNIT II / Q3 — SOLVED NUMERICAL

Disease data: Accuracy, Precision, Recall, F1

Given: TP = 50, FP = 5, FN = 10, TN = 35, total = 100.

Accuracy  = (TP + TN) / total = (50 + 35) / 100 = 0.85 = 85%
Precision = TP / (TP + FP) = 50 / (50 + 5) = 50/55 ≈ 0.909 = 90.9%
Recall    = TP / (TP + FN) = 50 / (50 + 10) = 50/60 ≈ 0.833 = 83.3%
F1-Score  = 2·P·R/(P+R) = 2(0.909)(0.833)/(0.909+0.833) ≈ 0.869 = 86.9%

ASSIGNMENT 2 · UNIT II / Q4–Q5

MAE, MSE, RMSE, R²

In regression the prediction is a number, so metrics are built from error = |actual − predicted|:

  • MAE = (1/n)Σ|y − ŷ|. Average absolute error, in original units. Less affected by outliers — a robust metric.
  • MSE = (1/n)Σ(y − ŷ)². Squaring punishes large errors more. Easy to optimize in training (differentiable).
  • RMSE = √MSE. Square root of MSE — back in original units for easy interpretation. Sensitive to large errors.
  • R² = 1 − SSres/SStot. How much output variance the model explains (0 to 1; 1 = perfect). Useful for comparing models across scales.

Designing a regression evaluation experiment (steps + why)

  • Step 1 — Split data (train/validation/test): so the model is tested on unseen data and overfitting is caught.
  • Step 2 — Fix a baseline: e.g. a mean predictor; shows whether the model beats the trivial option.
  • Step 3 — Fit on train, tune on validation: choose hyperparameters by validation MAE/RMSE; keep test untouched.
  • Step 4 — Report all three metrics: MAE (typical error size), RMSE (big-error penalty), R² (variance explained) — together they give the full picture.
  • Step 5 — Check residuals: errors randomly spread or patterned; a pattern means something is missing from the model.

RMSE = √100 = 10

Here all three errors equal 10, so MAE and RMSE both come to 10. Remember: RMSE is always ≥ MAE — equal only when all errors are identical.

ASSIGNMENT 3 · UNIT III / Q1

Linear regression + role of slope and intercept

Linear regression finds a straight-line relation between input X and continuous output Y: ŷ = a + bx. Goal: the line passing closest to the data points.

  • Slope (b): how much Y changes per 1-unit rise in X — the strength and direction. Positive slope = they rise together; near zero ≈ no linear relation.
  • Intercept (a): where the line cuts the Y-axis at X = 0 — the starting level / baseline value.

Example: if the study-hours (X) to marks (Y) model is ŷ = 30 + 5x, each extra hour adds ~5 marks (slope), with a base of 30 marks at zero hours (intercept).

ASSIGNMENT 3 · UNIT III / Q2–Q3 — SOLVED NUMERICAL

Regression equation + line of best fit

Given: X = [2, 4, 6, 8], Y = [3, 7, 5, 10]. Formulas: b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)², a = ȳ − bx̄.

x-mean = (2+4+6+8)/4 = 5,  y-mean = (3+7+5+10)/4 = 6.25
x-dev:  −3, −1, +1, +3        → squares: 9+1+1+9 = 20
y-dev:  −3.25, +0.75, −1.25, +3.75
products: 9.75 − 0.75 − 1.25 + 11.25 = 19.0
b = 19/20 = 0.95
a = 6.25 − 0.95×5 = 6.25 − 4.75 = 1.5
Equation: ŷ = 1.5 + 0.95x

How the best-fit line is found: it is the line minimizing the sum of squared errors (SSE) — the least squares method. Errors are squared so positives and negatives don't cancel and big mistakes are penalized more. The formulas above come from this minimization (setting SSE's derivative to zero). The cost function J = (1/2n)Σ(ŷ−y)² is this SSE in scaled form — gradient descent minimizes exactly it.

ASSIGNMENT 3 · UNIT III / Q4–Q5

Multicollinearity + MAE/RMSE repeat

Multicollinearity means two or more input features of a multiple regression are strongly correlated with each other (e.g. both “total marks” and “average marks” as features). Effects:

  • Coefficients turn unstable — small data changes swing values wildly.
  • Interpreting each feature's effect gets hard (standard errors inflate).
  • Predictions may barely suffer, but explanation and feature selection break.
  • Fix: drop one of the correlated features, or use regularization (Ridge/Lasso).

Q5 numerical (MAE/RMSE): the values repeat Assignment-2 Q6 exactly — Actual [100, 200, 150], Predicted [110, 190, 160]. So the answer is the same: MAE = 10, RMSE = 10 (see Assignment-2 Q6 for steps). Write the same method at both places in the exam.

ASSIGNMENT 3 · UNIT III / Q6–Q7

Sigmoid + logistic vs linear regression

Sigmoid function: σ(z) = 1 / (1 + e−z). It squashes any real number into 0–1 (S-shaped curve, 0.5 in the middle). Significance: logistic regression converts its linear combination z = w·x + b into a probability through it; the class is decided by the 0.5 threshold (≥ 0.5 → class 1).

Beware the exam trap: despite “regression” in the name, logistic regression is a classification algorithm. Write one line: linear regression tells “how much”, logistic regression tells “which class”.
