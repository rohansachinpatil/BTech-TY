01 / MCQ ANSWERS WITH REASON

10 MCQs — answer aur short logic

  1. Partial order — answer: d) reflexive and transitive

    Partial order reflexive, antisymmetric aur transitive hota hai. Diye gaye options mein sabse complete choice d hai. Exam mein antisymmetric word aaye toh use bhi likho.

  2. Regular language construction — answer: d) All of the mentioned

    Regular language basic languages se Union, Concatenation aur Kleene* teenon se banta hai. Tumhare QB mein “cannot be obtained” likha hai; ye likely typo hai, sahi meaning “can be obtained” hai.

  3. Octal number divisible by 3 — answer: b) 3

    Remainder 0, 1, 2 ke liye 3 states chahiye. Ek state remainder 0 yani accept state hoga. Isliye minimum 3 states.

  4. FA ke 5-tuple mein kaun nahi — answer: d) Output Alphabet

    FA ka 5-tuple Q, Σ, δ, q0, F hota hai. Output alphabet FA ka part nahi hai; wo Moore aur Mealy machines mein hota hai.

  5. Length at most 2, Σ = {0, 1} — answer: a) 7

    Length 0 ke 1 string (ε), length 1 ke 2 strings, length 2 ke 4 strings. Total 1 + 2 + 4 = 7. QB mein “(Σr)*” likha hai; iska meaning Σ* samjho.

  6. Myhill-Nerode — answer: d) Nerode

    Sahi theorem Myhill-Nerode theorem hai: language regular hai iff Nerode equivalence classes finite hain. Isliye “Nerode” answer likho.

  7. Simple primitive language se generation — answer: b) It takes no auxiliary memory

    Regular language ko finite-state device recognize karta hai aur use extra stack ya tape memory nahi chahiye. Option a) mein “infinite states” likha hai, jo galat hai; sahi word finite states hai.

  8. {0, 01} ko kaun represent nahi karta — answer: d) {0} ^ {01}

    Options a), b), c) sabhi same set {0, 01} likhne ke alag tareeke hain. Option d) wali notation is language ko represent nahi karti.

  9. Concatenation operation — answer: b) Dot

    Concatenation ko dot operation kehte hain. Jaise A.B ka matlab A ke baad B jodna hai.

  10. R with Φ concatenation — answer: b) Φ

    Empty set ke saath concatenation hamesha empty deta hai: R.Φ = Φ. Jaise zero se multiply karne par zero milta hai.

02 / THEORY Q1

Context-free language vs regular language

Regular language simple pattern wali language hai, jise bina kuch yaad rakhe check kiya ja sakta hai — machine ko sirf ye pata hota hai ki wo abhi kaunse state mein hai. Context-free language (CFL) usse powerful hai, kyunki usme nesting ya counting jaisi structure hoti hai, jiske liye machine ko purani cheezein yaad rakhni padti hain.

Yaad rakhne ka simple rule: agar pattern ko check karne ke liye counting ya matching chahiye (jaise khule brackets band karna), toh wo regular nahi ho sakti — uske liye stack wali memory chahiye, aur wahi CFL ka area hai.

EXAM DEFINITION

Every regular language is also context-free, but every context-free language is not regular.

Exam mein ek line zaroor likho: anbn regular nahi hai kyunki a's ki ginti yaad rakhne ke liye unbounded memory chahiye, aur FA ke paas sirf finite states hain.

03 / THEORY Q2

Context-free grammar ka concept

CFG language generate karne ke rules ka set hai. Ise 4 parts se define karte hain: G = (V, T, P, S). Har part ka role alag hai, isliye pehle chaaron ko ek example ke saath samjho.

  • V (variables / non-terminals): aise symbols jo aage expand hote hain, jaise S.
  • T (terminals): final symbols jo string mein dikhte hain, jaise a, b.
  • P (productions): replacement rules, jaise S → aSb | ε. Har rule ke left side par exactly ek variable hota hai — isi ko “context-free” kehte hain.
  • S (start symbol): derivation yahin se shuru hoti hai.

Derivation ka worked example

S ⇒ aSb ⇒ aaSbb ⇒ aabb
Rule: S → aSb | ε
Language: anbn

Har step mein ek variable apne rule se replace hota hai. Agar har baar leftmost variable expand karo toh use leftmost derivation kehte hain; rightmost expand karo toh rightmost derivation. Dono se same string banti hai.

Jab derivation mein sirf grammar symbols hon (terminals + variables mix), use sentential form kehte hain — jaise upar aaSbb ek sentential form hai. Jab sirf terminals bachen, wo final string hoti hai. Isi process ko tree mein dikhaya jaye toh use parse tree kehte hain: root S, leaves final string, aur har internal node apne production ko follow karta hai.

Grammar ki sabhi final strings ka set language of grammar, L(G) hai. Agar ek string ke do alag parse trees ban jayein, toh grammar ambiguous kehlati hai — ye Unit 3 ka important exam point hai.

EXAM DEFINITION

A context-free grammar is a 4-tuple G = (V, T, P, S) where every production has a single variable on its left-hand side.

04 / THEORY Q3

Regular expression ke operators

Regular expression pattern likhne ka short tareeka hai. Teen basic operators yaad rakho, phir do helpful shortcuts:

  • Union (+ ya |): choice. 0 + 1 ka matlab “0 ya 1”.
  • Concatenation (dot): sequence. 0.1 ka matlab “pehle 0, phir 1”, yani 01. Dot aksar chhupa lete hain, 01 likh dete hain.
  • Kleene star (*): zero ya more repeat. 0* ka matlab ε, 0, 00, 000, …
  • Plus (+ as superscript, R+): one-or-more repeat, jaise a+ ka matlab a, aa, aaa, … (lekin ε nahi).
  • Optional (?): zero-or-one, jaise a? ka matlab ε ya a.

Precedence order fix hai: star > concatenation > union. Isliye 0 + 01 ka matlab 0 + (0.1) hai, aur ab* ka matlab a(b*) hai, (ab)* nahi.

RE banane ke 2 ready examples

  • “01” par end: pehle kuch bhi, phir 01 — (0 + 1)*01.
  • “00” contain kare: beech mein 00, aage-peeche kuch bhi — (0 + 1)*00(0 + 1)*.

Exam tip: RE likhne ke baad 2 accept aur 1 reject string test karke dikhao — examiner ko lagta hai concept clear hai.

05 / THEORY Q4

Finite Automata ke applications

FA sirf theory nahi hai — jahan bhi input ko step-by-step scan karke decision lena ho, wahan FA logic kaam aata hai. Har application ke saath mechanism ek line mein samjho:

  1. Text search aur pattern matching

    Editor ya grep jaisi tools keyword ka automaton banakar text ko ek pass mein scan karti hain. Ye syllabus mein di hui direct application hai — pattern milte hi match report hota hai.

  2. Lexical analysis

    Compiler keywords, identifiers aur numbers ke RE patterns se DFA banakar source code ko tokens mein todta hai. Har token type ek accept state hota hai.

  3. Protocol aur control systems

    Traffic light, vending machine, elevator ya network protocol ke modes states hote hain aur events transitions. FA se check hota hai ki galat sequence kabhi execute na ho.

  4. Hardware design

    Sequential circuits (counters, sequence detectors) seedha FA se design hote hain — har flip-flop combination ek state hai.

  5. Input validation

    Email, phone number ya OTP jaise formats ke patterns FA se validate hote hain — galat character aate hi machine reject state mein jaati hai.

  6. Game logic aur AI states

    Game characters ke modes (idle, attack, escape) ek state machine hote hain; conditions transitions trigger karti hain.

07 / THEORY Q6

Mealy Machine ko Moore Machine mein convert karna

QB mein “Melay” likha hai; standard spelling Mealy Machine hai. Rule simple hai: Mealy mein output transition (edge) par hota hai, Moore mein output state (node) par hota hai. Isliye output ko transition se uthakar next state par chipka do — aur jahan conflict ho, wahan state split karo.

Conversion steps

  • Step 1: Har Mealy transition present-state —input/output→ next-state ko dekho.
  • Step 2: Next state ke liye output wali nayi Moore state banao, jaise q1/1 ka matlab state q1 jiska output 1.
  • Step 3: Agar ek hi state mein alag outputs ke saath entry ho rahi hai, toh us state ko split karo — ek copy har output ke liye.
  • Step 4: Start state ke liye alag Moore start state banao; baaki transitions same input par copy karo.

01 / MCQ ANSWERS WITH REASONS

10 MCQs — answers with short logic

  1. Partial order — answer: d) reflexive and transitive

    A partial order is reflexive, antisymmetric, and transitive. Among the given options, d is the most complete choice. If the antisymmetric option appears in the exam, include it too.

  2. Regular language construction — answer: d) All of the mentioned

    Regular languages are built from basic languages using Union, Concatenation, and Kleene* — all three. Your QB says “cannot be obtained”; that is likely a typo, the correct meaning is “can be obtained”.

  3. Octal number divisible by 3 — answer: b) 3

    You need 3 states for remainders 0, 1, and 2. The remainder-0 state is the accept state. So the minimum is 3 states.

  4. Not part of the FA 5-tuple — answer: d) Output Alphabet

    The FA 5-tuple is Q, Σ, δ, q0, F. The output alphabet is not part of it; it belongs to Moore and Mealy machines.

  5. Length at most 2, Σ = {0, 1} — answer: a) 7

    1 string of length 0 (ε), 2 of length 1, 4 of length 2. Total 1 + 2 + 4 = 7. The QB writes “(Σr)*”; read it as Σ*.

  6. Myhill-Nerode — answer: d) Nerode

    The correct theorem is the Myhill-Nerode theorem: a language is regular iff its Nerode equivalence classes are finite. So “Nerode” is the answer.

  7. Generation from simple primitive languages — answer: b) It takes no auxiliary memory

    A regular language is recognized by a finite-state device and needs no extra stack or tape memory. Option a) says “infinite states”, which is wrong; the correct word is finite states.

  8. Does not represent {0, 01} — answer: d) {0} ^ {01}

    Options a), b), and c) are all different ways of writing the same set {0, 01}. Only the notation in option d) does not represent this language.

  9. Concatenation operation — answer: b) Dot

    Concatenation is the dot operation. A.B means A followed by B.

  10. Concatenation of R with Φ — answer: b) Φ

    Concatenation with the empty set always gives empty: R.Φ = Φ. Just like multiplying by zero gives zero.

02 / THEORY Q1

Context-free vs regular languages

A regular language is a simple pattern language that can be checked without remembering anything — the machine only knows which state it is in. A context-free language (CFL) is more powerful: it handles nesting or counting structures that require the machine to remember past symbols.

Simple rule of thumb: if checking the pattern needs counting or matching (like closing opened brackets), it cannot be regular — it needs stack memory, and that is exactly the CFL territory.

03 / THEORY Q2

The concept of a context-free grammar

A CFG is a set of rules that generates a language. It is defined by 4 parts: G = (V, T, P, S). Understand each part with one example first.

  • V (variables / non-terminals): symbols that expand further, e.g. S.
  • T (terminals): final symbols appearing in strings, e.g. a, b.
  • P (productions): replacement rules, e.g. S → aSb | ε. Every rule has exactly one variable on the left — that is what “context-free” means.
  • S (start symbol): every derivation begins here.

Worked derivation example

S ⇒ aSb ⇒ aaSbb ⇒ aabb
Rule: S → aSb | ε
Language: anbn

Each step replaces one variable using a rule. Expanding the leftmost variable every time is a leftmost derivation; expanding the rightmost is a rightmost derivation. Both build the same string.

A string of grammar symbols appearing mid-derivation is a sentential form — e.g. aaSbb above. When only terminals remain, it is a final string. Drawing this process as a tree gives a parse tree: root S, leaves the final string, every internal node following its production.

The set of all final strings is the language of the grammar, L(G). If one string gets two different parse trees, the grammar is ambiguous — an important Unit 3 exam point.

EXAM DEFINITION

A context-free grammar is a 4-tuple G = (V, T, P, S) where every production has a single variable on its left-hand side.

04 / THEORY Q3

Operators of regular expressions

A regular expression is a short way of writing a pattern. Memorize three basic operators first, then two handy shortcuts:

  • Union (+ or |): choice. 0 + 1 means “0 or 1”.
  • Concatenation (dot): sequence. 0.1 means “first 0, then 1”, i.e. 01. The dot is often hidden and written just as 01.
  • Kleene star (*): zero or more repeats. 0* means ε, 0, 00, 000, …
  • Plus (R+): one-or-more repeats, e.g. a+ means a, aa, aaa, … (but not ε).
  • Optional (?): zero-or-one, e.g. a? means ε or a.

Precedence is fixed: star > concatenation > union. So 0 + 01 means 0 + (0.1), and ab* means a(b*), not (ab)*.

Important algebraic laws
LawExample
Union commutative/idempotentA + B = B + A, A + A = A
Concatenation associative(AB)C = A(BC)
DistributiveA(B + C) = AB + AC
Identity/annihilatorA + Φ = A, A.ε = A, A.Φ = Φ
Star propertiesA* = ε + AA*, (A*)* = A*

2 ready-made RE building examples

  • Ending with “01”: anything first, then 01 — (0 + 1)*01.
  • Containing “00”: 00 in the middle, anything around — (0 + 1)*00(0 + 1)*.

Exam tip: after writing an RE, test it with 2 accepting and 1 rejecting string — it signals clear concepts to the examiner.

05 / THEORY Q4

Applications of Finite Automata

FA is not just theory — wherever an input must be scanned step by step to reach a decision, FA logic applies. Understand each application with its one-line mechanism:

  1. Text search and pattern matching

    Tools like editors and grep build an automaton for the keyword and scan text in a single pass. This is the direct syllabus application — a match is reported the moment the pattern is found.

  2. Lexical analysis

    The compiler builds DFAs from RE patterns of keywords, identifiers, and numbers, then breaks source code into tokens. Each token type is an accept state.

  3. Protocols and control systems

    Traffic lights, vending machines, elevators, and network protocols have modes as states and events as transitions. FA verifies that a wrong sequence can never execute.

  4. Hardware design

    Sequential circuits (counters, sequence detectors) are designed directly from FA — every flip-flop combination is a state.

  5. Input validation

    Formats like email, phone numbers, or OTPs are validated by FA patterns — a wrong character sends the machine to a reject state at once.

  6. Game logic and AI states

    Game character modes (idle, attack, escape) form a state machine; conditions trigger the transitions.

06 / THEORY Q5

Difference between DFA and NFA

Both have equal power (both recognize regular languages); only the rules differ. A DFA has exactly one path in every situation; an NFA allows choices and shortcut (epsilon) moves.

Do write one line in the exam: NFA is convenient for design, DFA for execution.

07 / THEORY Q6

Converting a Mealy Machine to a Moore Machine

The QB spells it “Melay”; the standard spelling is Mealy Machine. The rule is simple: a Mealy machine carries output on the transition (edge), a Moore machine on the state (node). So lift the output off the transition onto the next state — and split the state wherever there is a conflict.

Conversion steps

  • Step 1: Look at every Mealy transition present-state —input/output→ next-state.
  • Step 2: Create a Moore state carrying that output for the next state, e.g. q1/1 means state q1 with output 1.
  • Step 3: If one state is entered with different outputs, split it — one copy per output.
  • Step 4: Create a separate Moore start state; copy the remaining transitions on the same inputs.

Follow this systematic 4-step method for DFA construction, then apply it to the example:

  • Step 1 — What to remember: decide which past of the input must be remembered.

Mealy vs Moore machines

Both are finite automata with output — they take input and produce output. The only difference is where the output sits: on the edge (Mealy) or on the node/state (Moore). That single difference changes timing and state count.

Lexical analysis in detail

Lexical analysis is the first phase of a compiler. It breaks source code characters into tokens. Fix three terms first — examiners ask their definitions separately:

Token vs lexeme vs pattern
TermMeaningExample
TokenA name + value pair for a meaningful unit[identifier:a]
LexemeThe actual text found in source codea
PatternThe rule (RE) describing the lexemeidentifier: letter(letter|digit)*

Input–output example

Input:  int a = 5;
Tokens: [keyword:int] [identifier:a] [=] [number:5] [;]

What the lexical analyzer does

  • Removes whitespace and comments.
  • Recognizes keywords, identifiers, constants, and operators.
  • Creates identifier entries in the symbol table.
  • Tracks line numbers and reports lexical errors on invalid tokens.
  • Follows the longest-match rule: ifx is one identifier, not keyword if + x.
  • Uses lookahead to resolve confusion, e.g. = vs ==.

Inside flow: RE → NFA → DFA → minimal DFA. Write each token pattern as an RE, build its automaton, then scan the code in one pass taking the longest match. Do write the exam line: lexical analysis runs before syntax analysis and feeds a clean token stream to the parser.

Memory hook: a DFA remembers suffixes; Mealy speaks on the edge, Moore in the state; the lexer turns patterns into tokens.
