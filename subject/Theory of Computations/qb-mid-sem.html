01 / MCQ ANSWERS WITH REASON

10 MCQs — answer aur short logic

  1. Partial order — answer: d) reflexive and transitive

    Partial order reflexive, antisymmetric aur transitive hota hai. Diye gaye options mein sabse complete choice d hai. Exam mein antisymmetric word aaye toh use bhi likho.

  2. Regular language construction — answer: d) All of the mentioned

    Regular language basic languages se Union, Concatenation aur Kleene* teenon se banta hai. Tumhare QB mein “cannot be obtained” likha hai; ye likely typo hai, sahi meaning “can be obtained” hai.

  3. Octal number divisible by 3 — answer: b) 3

    Remainder 0, 1, 2 ke liye 3 states chahiye. Ek state remainder 0 yani accept state hoga. Isliye minimum 3 states.

  4. FA ke 5-tuple mein kaun nahi — answer: d) Output Alphabet

    FA ka 5-tuple Q, Σ, δ, q0, F hota hai. Output alphabet FA ka part nahi hai; wo Moore aur Mealy machines mein hota hai.

  5. Length at most 2, Σ = {0,1} — answer: a) 7

    Length 0 ke 1 string (ε), length 1 ke 2 strings, length 2 ke 4 strings. Total 1 + 2 + 4 = 7. QB mein “(Σr)*” likha hai; iska meaning Σ* samjho.

  6. Myhill-Nerode — answer: d) Nerode

    Sahi theorem Myhill-Nerode theorem hai: language regular hai iff Nerode equivalence classes finite hain. Isliye “Nerode” answer likho.

  7. Simple primitive language se generation — answer: b) It takes no auxiliary memory

    Regular language ko finite-state device recognize karta hai aur use extra stack ya tape memory nahi chahiye. Option a) mein “infinite states” likha hai, jo galat hai; sahi word finite states hai.

  8. {0,01} ko kaun represent nahi karta — answer: d) {0} ^ {01}

    Options a), b), c) sabhi same set {0,01} likhne ke alag tareeke hain. Option d) wali notation is language ko represent nahi karti.

  9. Concatenation operation — answer: b) Dot

    Concatenation ko dot operation kehte hain. Jaise A.B ka matlab A ke baad B jodna hai.

  10. R with Φ concatenation — answer: b) Φ

    Empty set ke saath concatenation hamesha empty deta hai: R.Φ = Φ. Jaise zero se multiply karne par zero milta hai.

02 / THEORY Q1

Context-free language vs regular language

Regular language simple pattern wali language hai, jise bina yaad rakhe check kiya ja sakta hai. Context-free language usse powerful hai, kyunki usme nesting ya counting jaisi structure handle hoti hai.

Exam table / power ka farq
PointRegular languageContext-free language
MachineFinite Automata, bina extra memoryPushdown Automata, stack memory ke saath
GrammarRegular grammarContext-free grammar
ExampleStrings ending with 01anbn, jaise aabb
Memory logicSirf current state yaad rehta haiStack par open symbols yaad rehte hain

Yaad rakhne ki analogy: Regular language = token counter bina parchi ke; CFL = bracket matching ke liye ek stack wali parchi.

EXAM DEFINITION

Every regular language is also context-free, but every context-free language is not regular.

03 / THEORY Q2

Context-free grammar ka concept

CFG 4 parts se banti hai: variables, terminals, productions aur start symbol. Ise G = (V, T, P, S) likhte hain.

  • V: non-terminals, jaise S, jo aage expand hote hain.
  • T: terminals, final symbols jaise a, b.
  • P: rules, jaise S → aSb | ε.
  • S: start symbol, derivation yahin se shuru hoti hai.
S ⇒ aSb ⇒ aaSbb ⇒ aabb
Rule: S → aSb | ε
Language: anbn

Jab derivation mein sirf grammar symbols hon, use sentential form kehte hain. Jab sirf terminals bachen, wo final string hoti hai. Isi process ko tree mein dikhaya jaye toh use parse tree kehte hain. Grammar ki sabhi final strings ka set language of grammar, L(G) hai.

04 / THEORY Q3

Regular expression ke operators

Regular expression pattern likhne ka short tareeka hai. Teen basic operators yaad rakho:

  • Union (+ ya |): choice. 0 + 1 ka matlab “0 ya 1”.
  • Concatenation (dot): sequence. 0.1 ka matlab “pehle 0, phir 1”, yani 01.
  • Kleene star (*): zero ya more repeat. 0* ka matlab ε, 0, 00, 000, …

Helpful operators: + ka matlab one-or-more repeat, jaise a+; ? ka matlab optional, jaise a?. Precedence order: star > concatenation > union. Isliye 0 + 01 ka matlab 0 + (0.1) hai.

Important algebraic laws
LawExample
Union commutative/idempotentA + B = B + A, A + A = A
Concatenation associative(AB)C = A(BC)
DistributiveA(B + C) = AB + AC
Identity/annihilatorA.ε = A, A.Φ = Φ
Star propertyA* = ε + AA*

05 / THEORY Q4

Finite Automata ke applications

  1. Text search aur pattern matching

    Editor ya command-line search keyword ka automaton banakar text ko ek pass mein scan karta hai. Ye syllabus mein di hui direct application hai.

  2. Lexical analysis

    Compiler keywords, identifiers aur numbers ko RE se DFA banakar tokenize karta hai.

  3. Protocol aur control systems

    Traffic light, vending machine, elevator ya network protocol ke states FA se model hote hain.

  4. Hardware aur validation

    Digital circuits aur input validation, jaise email ya OTP pattern check, FA logic use karte hain.

DFA ka transition function δ: Q × Σ → Q hota hai. NFA mein δ: Q × (Σ ∪ {ε}) → 2Q hota hai, yani set of states milta hai. Exam mein ek line zaroor likho: NFA design ke liye convenient hai, DFA execution ke liye.

07 / THEORY Q6

Mealy Machine ko Moore Machine mein convert karna

QB mein “Melay” likha hai; standard spelling Mealy Machine hai. Rule simple hai: Mealy mein output transition par hota hai, Moore mein output state par hota hai. Isliye output ko transition se uthakar next state par chipka do.

Conversion steps

  • Step 1: Har Mealy transition present-state —input/output→ next-state ko dekho.
  • Step 2: Next state ke liye output wali nayi Moore state banao, jaise q1/1.
  • Step 3: Agar ek hi state mein alag outputs ke saath entry ho rahi hai, toh us state ko split karo.
  • Step 4: Start state ke liye alag Moore start state banao; baaki transitions same input par copy karo.
Mealy example:
q0 --0/0--> q0
q0 --1/1--> q1
q1 --0/0--> q0
q1 --1/1--> q1

Moore idea:
q0-start --0--> [q0/0]
q0-start --1--> [q1/1]
[q0/0] --0--> [q0/0]
[q0/0] --1--> [q1/1]

Exam mein table aur chhota state diagram dono banao. Ek line likho: Moore machine mein usually states badh jaati hain, kyunki output alag hone par state split hoti hai.

08 / THEORY Q7

DFA construct karo — suitable example

Example lo: Σ = {0, 1} par wo strings jo “01” par end hoti hain. Socho tumne abhi tak suffix ka kitna part match kiya hai.

  • q0: start; abhi “01” ka koi useful suffix match nahi.
  • q1: last symbol 0 dekha, “0” match hua.
  • q2: accept; string “01” par end hui.

Test karo: 101 reject hogi, 1001 accept hogi. 5-tuple likho: Q = {q0, q1, q2}, Σ = {0, 1}, δ upar table jaisa, start q0, final {q2}.

10 / THEORY Q9

Lexical Analysis detail mein

Lexical analysis compiler ka pehla phase hai. Iska kaam source code ko characters se tokens mein todna hai. Token ka matlab meaningful unit, jaise keyword, identifier, number, operator ya separator.

Input-output example

Input:  int a = 5;
Tokens: [keyword:int] [identifier:a] [=] [number:5] [;]

Lexical analyzer kya-kya karta hai

  • Whitespace aur comments hatata hai.
  • Keywords, identifiers, constants aur operators pehchanta hai.
  • Symbol table mein identifier entry banata hai.
  • Line number track karta hai aur invalid token par lexical error deta hai.

Andar ka flow: RE → NFA → DFA → minimal DFA. Pehle token ka pattern RE se likho, phir uska automaton banao, phir code ko ek pass mein scan karke longest match wala token lo. Exam mein line zaroor likho: lexical analysis syntax analysis se pehle hoti hai aur parser ko clean token stream deti hai.

Memory hook: DFA suffix yaad rakhta hai; Mealy edge par bolta hai, Moore state par; lexer pattern ko token mein badalta hai.
